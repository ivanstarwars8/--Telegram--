# FocusOps — Telegram операционка дня

Система для проживания дня по сценариям A/B/C. Пользователь выбирает план, переключается по ходу дня, отмечает выполнение задач и получает аналитику. Архитектура разделена на FastAPI backend, aiogram v3 бота и сервисные воркеры на Celery.

## Архитектура

- **FastAPI (`app/`)** — REST API для бота и будущих клиентов.
- **Postgres** — хранение пользователей, шаблонов, дневных слепков, метрик.
- **Redis** — кэш и брокер для очередей.
- **Celery + Beat** — напоминания и расчёт статистики с учётом таймзон.
- **aiogram v3 (`bot/`)** — пользовательские сценарии и диалоги.
- **Docker Compose** — локальный запуск API, бота, воркеров, БД, Redis.

## Основные возможности

- Регистрация и персональные таймзоны.
- Шаблоны планов A/B/C и кастомные пресеты.
- Утренний выбор плана, переключения с политикой переноса.
- Статусы задач (todo/doing/done/skip) и лог фокус-сессий.
- Статистика по дням/неделям: streak, надёжность, стабильность, фокус-время.
- Планировщик напоминаний в Celery.
- Бот с быстрыми командами `/plan`, `/today`, `/next`, `/done`, `/skip`, `/stats`.

## Установка

1. Установите зависимости операционной системы: Docker, Docker Compose, Python 3.11, Poetry или pip, а также `make` (опционально).
2. Клонируйте репозиторий и перейдите в директорию проекта:

   ```bash
   git clone <repo_url>
   cd <repo_dir>
   ```

3. Скопируйте файл окружения и заполните его значениями:

   ```bash
   cp .env.example .env
   ```

   Минимальный набор переменных:

   - `POSTGRES_DSN`, `REDIS_DSN` — строки подключения к БД и Redis.
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_IDS` — токен бота и список админов.
   - `CELERY_BROKER_URL`, `CELERY_RESULT_BACKEND` — адреса брокера и backend Celery.
   - `API_BASE_URL` — адрес API, который использует бот (например, `http://api:8000`).

4. (Опционально) Для разработки без Docker создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

   Настройте Postgres и Redis локально, примените миграции `alembic upgrade head`, затем запустите FastAPI (`uvicorn app.main:app --reload`) и бота (`python bot/main.py`).

## Запуск через Docker

```bash
docker compose up --build
```

Сервисы:

- `api`: FastAPI на `http://localhost:8000`.
- `bot`: aiogram-поллинг.
- `worker`: Celery-воркер.
- `beat`: Celery Beat с крон расписанием.
- `postgres`, `redis` — инфраструктура.
