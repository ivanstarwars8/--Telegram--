# Focus Keeper Bot

Простой Telegram-бот для удержания фокуса и отслеживания срывов.

## Возможности
- Кнопка «Я срываюсь» запускает короткий диалог.
- Жёсткая поддержка в пару фраз, генерируется через GPT.
- Фильтр по цели: «Ведёт к маяку?»
- Логирование срывов и просмотр статистики за неделю (`/stats`).
- Ежедневные напоминания в 9:00 и 21:00.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Экспортируйте токены:
   ```bash
    export BOT_TOKEN=ваш_токен
    export OPENAI_API_KEY=ваш_ключ
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```
